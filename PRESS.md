# Press kit

Everything needed to write about, post or share Kiro. Short on purpose.

## One line

Kiro is a free, open-source Windows shell: a dynamic-island notch, a dock,
seasonal themes, AI in the notch, and a game layer that steps aside.

## Three lines

Kiro replaces the Windows taskbar with a notch and a dock. It is themed rather
than skinned — four surface styles and four seasonal effects — and Claude,
ChatGPT and Gemini answer inside the notch. When a game goes fullscreen,
everything hides at the OS level so the game keeps its direct-to-screen flip.

## Paragraph

Kiro is a desktop shell for Windows 10 and 11, written in Rust with Tauri. The
taskbar is replaced by two pieces of furniture: a spring-animated notch holding
music, system controls, a calendar, notes and a file shelf, and a dock that
mirrors the apps the user actually runs. Appearance is first-class — solid,
frosted or liquid glass, a Material You palette, four seasonal effects and a
custom mascot. AI lives in the notch, including a coding agent that reports its
state there. A performance layer raises the game's priority, mutes toasts and
hides Kiro's windows when a fullscreen game starts, then reverts everything on
exit. GPLv3, no telemetry, no account, no paid tier. Windows and Linux.

## What it is not

- Not a Windows modification, not a patcher, no DLL injection, nothing that
  touches game files. Anti-cheat protected processes are left alone.
- Not a paid product with a free tier. There is one build and it is the GPLv3 one.
